


# Register a transaction

## Goal

Allow the user to register a new financial transaction.

## Preconditions

- User is logged in
- An account exists

## Main flow

1. User opens Transactions.
2. User clicks "New Transaction".
3. User fills the form.
4. User saves.
5. System validates the data.
6. System creates the transaction.
7. Account balance is recalculated.
8. UI refreshes.
