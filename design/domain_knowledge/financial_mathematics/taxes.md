


# Taxes

Taxes are values deducted from a value an entity receives, or a value an entity owns the taxation entity (the government).

Multiple taxes can be applied at the same time, the questions that have to be made are:
- Why is the taxable entity being taxed (residency, citizenship)
- What value is being used to calculate the taxation value (gross income, property value)
- What is the timing of the tax (immediatly deducted, paid at the end of the year)

# Specific taxes description

## Income taxes

### Portugal

Portugal taxes individuals primarily based on **tax residency**. Residents are generally taxed on their worldwide income, while non-residents are taxed only on Portuguese-source income.



# What this means for the app

When actualizing a context view, that is, simulating for each day, an algorithm of this form should be applied:
- See if a taxes program can be applied
- See at which dates the tax is to be applied (only future dates)
- When reaching one of those dates, calculate its value
