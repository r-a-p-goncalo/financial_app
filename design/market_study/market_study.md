## Money manager

Money manager for phone is [here](https://play.google.com/store/apps/details?id=com.realbyteapps.moneymanagerfree&hl=en).

### Features

#### Features for tracking expenses

Allows for accounts and account groups, showing three totals:
- Assets, the sums of positive values across accounts
- Liabilities, the sums of negative values across accounts
- Total, the sum of these two values

Each account is able to show its deposit, its withdrawal, total values in a period of time, while also showing the current balance.

Adding expenses with:
- date,
- time,
- amount,
- note,
- description,
- category and subcategory

Adding dates uses an interactive window.

Adding amounts can be used with a calculator interface.

A note is a short text. When adding a note, autocomplete options show using previous notes.

Notes can be marked as important.

Description is a long text that can have a photo associated with.

Expenses can be bookmaked.

Expenses can be marked as repeat: Every day, weekdays, weekend, every 1/2/4 weeks, every month, end of the month, every 2/3/4/6 months, annually.

Allows addings transfers, which are close to expenses, without a category and with an origin and a target account.

In transfers, it is possible to add a fee to the transaction.

It is possible to copy entries with no date, current date and date of entry.

Just like adding expense / income transfer, bigger notes can be added.

#### Planning finances

For each category, a monthly budget can be added. The percentage overspended or underspended can then be querried.


#### Features for cross platform and managing data

It allows to backup data or exporting to excel

### What is missing

Modelling non-liquid assets is missing, there is only monetary value.

Entities are missing. It could be useful to know how much money you're owning someone for example.

Categories are very strict. There are categories and then subcategories. For things like dinning with friends in a special place, that could be both "going out with friends" and "food", we are forced to choose one, the other or create a new category that accomodates both.

The app is missing capability of studying the future.

The app is intuitive to use, but there is not much incentive for users to try out new features.

Categories for income and expenses are forced as different. Is this a necessary distinction? The user can add it if so.
